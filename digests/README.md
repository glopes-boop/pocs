# Digests de IA, ML e dados

Resumo diário (dias úteis, em pt-BR) de notícias, papers, releases e repositórios sobre agentes de IA, MCP, RAG e retrieval, plataformas de dados e governança de IA.

**Critério.** Cada item cita a fonte real (documentação oficial, release notes, arXiv, blogs de fornecedores, GitHub, X e Reddit) com link. Números de benchmark e preço são os que a fonte publicou e ficam marcados como do fornecedor ou dos autores quando não foram medidos de forma independente. Stars e licença dos repositórios foram conferidos na API do GitHub no dia indicado.

**Ângulo.** As seções "Para o gateway de contexto" e "Para quem monta brains analíticos" leem cada notícia contra um desenho de referência genérico: um gateway de contexto com PEP (API gateway) na borda, PDP sem estado que decide e falha fechado, recibos SHA-256 encadeados e brains analíticos só de leitura em ambiente regulado (LGPD). É um exercício de arquitetura, não a descrição de nenhum ambiente real.

**Sem afiliação.** Conteúdo pessoal, sem vínculo com empregador, fornecedor ou produto citado. Pode conter erros; confira a fonte antes de usar. Cada digest traz um diagrama (PNG) com o arquivo editável `.excalidraw` em [`assets/`](assets/).
